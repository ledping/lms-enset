Introduction aux Codes Numériques

Définition : Code

Un code est une représentation d'une grandeur dans une structure matérielle donnée. C'est une autre manière de représenter des nombres, utilisant des symboles et des règles spécifiques pour encoder l'information.

Dans les systèmes numériques, l'information est traitée sous forme binaire (0 et 1). Différents codes permettent de représenter cette information de manière adaptée à des applications spécifiques.

Concept Clé : Importance des Codes

Les codes sont essentiels pour :

  • Représenter efficacement l'information numérique
  • Détecter et corriger les erreurs de transmission
  • Faciliter les opérations arithmétiques
  • Adapter la représentation aux contraintes matérielles
  • Assurer la compatibilité entre différents systèmes

Classification des Codes

Les codes peuvent être classés selon plusieurs critères :

Code Binaire Naturel

Définition : Binaire Naturel

Le code binaire naturel ou binaire pur est le code directement associé à la base 2. C'est la représentation la plus simple et la plus directe des nombres en système numérique.

En base 2, les nombres sont représentés à l'aide de deux symboles : 0 et 1. Chaque position dans un nombre binaire représente une puissance de 2, en commençant par 2⁰ à droite.

Concept Clé : Représentation sur n bits

Un nombre binaire est généralement représenté sur un nombre fixe de bits (n). Le plus grand nombre décimal qu'on peut représenter sur n bits est :

Plage de valeurs

Valeur maximale = 2ⁿ - 1

Valeur minimale = 0 (pour les entiers non signés)

Caractéristiques importantes

  • Pondération : Chaque bit a un poids qui est une puissance de 2
  • Simplicité : Facile à comprendre et à implémenter
  • Calcul : Permet directement les opérations arithmétiques
  • Limitation : Représentation redondante pour certains nombres

Note : Le binaire naturel est le fondement de tous les autres codes binaires. La plupart des autres codes en dérivent ou y sont convertis pour les calculs.

Complément à Deux

Définition : Complément à Deux

Le complément à deux est une méthode de représentation des nombres entiers signés en binaire. Elle permet d'effectuer facilement les opérations arithmétiques (addition, soustraction) avec des nombres négatifs.

Concept Clé : Représentation des signes

Dans le complément à deux :

  • Le bit de poids fort représente le signe : 0 = positif, 1 = négatif
  • Les nombres positifs sont représentés comme en binaire naturel
  • Les nombres négatifs sont représentés par le complément à deux de leur valeur absolue

Méthode de calcul du complément à deux

Pour représenter un nombre négatif -X sur n bits :

Algorithme du complément à deux

1. Écrire la valeur absolue X en binaire sur n-1 bits (bit de signe à 0)

2. Inverser tous les bits (complément à un)

3. Ajouter 1 au résultat (ignorer les dépassements)

Outil : Calcul du Complément à Deux

Résultat :
Étapes de calcul :
Exemple détaillé : -5 sur 4 bits
Méthode 1 : Algorithme pas à pas
1. Valeur absolue de -5 : 5 → 0101 (sur 4 bits, bit de signe inclus)
2. Complément à un : 0101 → 1010
3. Ajouter 1 : 1010 + 1 = 1011
Résultat : -5 = 1011 en complément à deux sur 4 bits
Méthode 2 : Formule directe
Pour -5 sur 4 bits : 2⁴ - | -5 | = 16 - 5 = 11
11 en binaire : 1011
Résultat : -5 = 1011 en complément à deux

Avantages du complément à deux

  • Un seul zéro : Pas de problème de double représentation du zéro
  • Addition simple : Même circuit pour l'addition et la soustraction
  • Détection de dépassement : Facile à détecter
  • Extension de signe : Simple à étendre à plus de bits

Standard IEEE 754 pour les nombres réels

Définition : Virgule flottante

Le standard IEEE 754 définit la représentation des nombres à virgule flottante en informatique. Il permet de représenter des nombres réels avec une grande plage de valeurs.

Concept Clé : Structure générale

Un nombre en virgule flottante se compose de trois parties :

± mantisse × baseexposant

Où :
• Signe : 0 pour positif, 1 pour négatif
• Mantisse : partie fractionnaire (normalisée)
• Exposant : puissance à laquelle la base est élevée

Formule de calcul IEEE 754

Valeur = (-1)S × 2(E - 127) × (1 + M)

Où :
• S = bit de signe (0 ou 1)
• E = exposant biaisé (8 bits, valeur 1-254)
• M = mantisse (23 bits, valeur fractionnaire entre 0 et 1-2-23)

Exemple : -6.625 en IEEE 754

Étape 2 : Normalisation

(déplacer la virgule de 2 positions vers la gauche)

Étape 3 : Déterminer les composants
• Signe : 1 (négatif)
• Exposant : 2 + 127 = 129 = 100000012
• Mantisse : .10101 (étendue à 23 bits)

Étape 4 : Représentation finale
Signe | Exposant | Mantisse
1 | 10000001 | 10101000000000000000000
Résultat : 1 10000001 10101000000000000000000

Valeurs spéciales IEEE 754

  • Zéro : Exposant = 0, Mantisse = 0 (signe ±0)
  • Infini : Exposant = 255, Mantisse = 0
  • NaN : Exposant = 255, Mantisse ≠ 0 (Not a Number)
  • Nombres dénormalisés : Exposant = 0, Mantisse ≠ 0

Note : Le biais de 127 pour l'exposant permet de représenter des exposants négatifs sans bit de signe supplémentaire. L'exposant biaisé varie de 1 à 254 (0 et 255 sont réservés).

Code Gray (Binaire Réfléchi)

Définition : Code Gray

Le code Gray, aussi appelé code binaire réfléchi, est un code non pondéré où deux valeurs successives ne diffèrent que d'un seul bit. Il est particulièrement utile pour éviter les erreurs lors des transitions dans les systèmes numériques.

Concept Clé : Avantage principal

Dans le code binaire naturel, lors du passage d'une valeur à la suivante, plusieurs bits peuvent changer simultanément (ex: 0111 → 1000). Si les bits ne changent pas exactement au même instant, des valeurs erronées peuvent apparaître temporairement. Le code Gray élimine ce problème.

Méthode de construction du code Gray

Le code Gray peut être construit par la méthode des miroirs :

Algorithme des miroirs

1. Commencer avec 0 et 1 pour 1 bit

2. Pour ajouter un bit, prendre la séquence existante et : • Écrire la séquence en ordre inverse • Ajouter 0 devant la séquence originale • Ajouter 1 devant la séquence inversée

Exemple : Conversion Binaire → Gray
Binaire : 0101 (5)
Calcul :
G3 = B3 = 0
G2 = B3 ⊕ B2 = 0 ⊕ 1 = 1
G1 = B2 ⊕ B1 = 1 ⊕ 0 = 1
G0 = B1 ⊕ B0 = 0 ⊕ 1 = 1
Gray : 0111

Applications du code Gray

  • Encodeurs de position : Capteurs rotatifs, linéaires
  • Systèmes de contrôle : Éviter les états transitoires
  • Communications : Réduction des erreurs de transmission
  • Circuits asynchrones : Synchronisation des signaux

Code BCD (Binary Coded Decimal)

Définition : Code BCD

Le code BCD (Binary Coded Decimal) est un code pondéré qui représente chaque chiffre décimal (0-9) par son équivalent binaire sur 4 bits. C'est un compromis entre la représentation décimale et binaire.

Concept Clé : Principe de codage

Dans le code BCD, chaque chiffre décimal est codé indépendamment sur 4 bits selon la table de conversion standard. Les nombres supérieurs à 9 utilisent plusieurs groupes de 4 bits.

  • BCD 8421 : Standard (poids 8-4-2-1)
  • BCD 5421 : Poids 5-4-2-1
  • BCD 2421 : Poids 2-4-2-1
  • BCD excès-3 : BCD + 3 (auto-complémentaire)
  • BCD Aiken : Poids 2-4-2-1

Note : Le BCD est particulièrement utile dans les applications où la précision décimale est cruciale et où les conversions binaire-décimal sont fréquentes, comme dans les systèmes financiers et les calculatrices.

Code "p parmi n"

Définition : Code p parmi n

Un code p parmi n est un code où chaque mot de code contient exactement p bits à 1 parmi n bits totaux. La position des 1 détermine la valeur codée.

Concept Clé : Propriété de détection d'erreur

Ces codes ont la propriété intrinsèque de détecter certaines erreurs : toute modification qui change le nombre de 1 dans un mot de code est automatiquement détectée.

Nombre de combinaisons

Le nombre de mots de code possibles dans un code p parmi n est donné par :

C(n, p) = n! / (p! × (n-p)!)

Le code postal utilisé par La Poste est un code 3 parmi 5. Chaque chiffre décimal est représenté par 5 barres, dont exactement 3 sont épaisses (1) et 2 sont fines (0).

Avantages des codes p parmi n

  • Détection d'erreurs : Toute erreur simple qui change le nombre de 1 est détectée
  • Équilibre : Nombre constant de 1 facilite la transmission
  • Simplicité : Facile à encoder et décoder
  • Applications pratiques : Codes barres, systèmes de tri

Note : Les codes p parmi n font partie de la famille des codes à poids constant. Ils sont particulièrement utiles dans les applications où la détection d'erreur est importante et où le débit de données n'est pas critique.
